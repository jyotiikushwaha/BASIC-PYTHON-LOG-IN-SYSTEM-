# Python Login System

A beginner-friendly Python project that simulates a basic login system.
The user gets 3 attempts to enter the correct username and password.
If all attempts are exhausted, the account gets locked.

Features:
- Username & password validation
- Limited login attempts (3 tries)
- Real-time remaining attempts display
- Account lockout after failed attempts
- Clean console output

Concepts Used:
- Variables & Data Types
- Input & Output
- Conditional Statements (if/else)
- Loops (for loop)
- Break & Continue
- f-strings

How to Run:
1. Clone the repository
2. Run: python login.py
